# UnipopWhooWhoo
Match making for job search (авторская конфигурация 1С:Предприятие)

Конфигурация носит условное название: 
# ЮниУгу:Поиск работы

Она позиционируется как конфигурация от Зубкова Руслана, а чтобы она не звучала как Зубков:Поиск работы, используется филлерное обозначение ЮниУгу (где Юни - от Юнипоп).

**Данная конфигурация создаётся исключительно в интересах Московского Университета имени С. Ю. Витте, а не музыкального лейбла Юнипоп.**

**Связь с лейблом Unipop чисто шуточная.** 
Она может выражаться в дальнейшем развитии программы, создании форка как для Витте, так и для Юнипоп, 
чтобы протекала коллаборация между университетом и лейблом, 
чтоб студентки делали аэробику под музыку от артистов лейбла,
чтоб песни попадали в компьютерные игры.
Потому что я знаком с творчеством группы Terelya, она у меня носит титул выдры.
